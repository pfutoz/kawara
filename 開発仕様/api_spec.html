全API連携アーキテクチャ概要

院内かわら版を中心とするデータハブ構想と各種インターフェースの位置づけ

院内かわら版は、単なる掲示板ではなく、電子カルテ端末、医事システム、院内サイネージ、Googleカレンダー、LINE、院内ネットワーク複合機、および災害BCP安否確認システムをつなぐ「院内情報伝達のハブ」として機能します。

System Topology & Interface Map
Core REST API
📡 外部連携 REST API
記事取得、検索、カレンダーイベント展開、サマリー統計、UI埋め込みウィジェットを院内の他Webシステムに提供。
Google Cloud
📅 Google カレンダー API
OAuth2 JWTサービスアカウントによる予定の作成・更新・削除とローカルDBキャッシュ自動同期、個人Web Intent登録。
LINE Bot
💬 LINE Messaging API
数字4桁コードによるスタッフ紐付け、記事の対象部署別一斉プッシュ、1タップ了解・欠席・質問ポストバック処理。
Network Print
🖨️ 自動印刷・排紙 API
Windowsスプーラ連携により、重要ポスターや不在者まとめ日報を各ステーション・医局の指定給紙トレイへ即時排紙。
Disaster BCP
🚨 災害BCP・安否確認 API
緊急災害モードの発令判定、全職員点呼の回答状況（無事/注意/危険/未回答）集計データのリアルタイム配信。
SSO & Master
🔐 統合認証 ＆ 職員マスタ
auth_db によるJWT認証トークン検証と、stf_api による最新職員プロファイル（部署・役職・電話）同期。

外部連携共通プロトコル仕様

共通ヘルパー (includes/api_helper.php) による統一仕様

項目 仕様・設定値
ベースURL http://[サーバーIP]/kawara/api (本番: http://192.168.1.16/kawara/api)
通信暗号化 HTTP / HTTPS (院内セキュアイントラネット通信)
文字コード UTF-8 (日本語文字列はエスケープなしの生UTF-8で返却: JSON_UNESCAPED_UNICODE)
CORS設定 Access-Control-Allow-Origin: * (他WebシステムやローカルJSからの呼び出し許可)
プリフライト OPTIONS リクエスト時に自動的に 200 OK を返却して即時終了
キャッシュ制御 Cache-Control: no-cache, no-store, must-revalidate (リアルタイム性担保)
標準レスポンスフォーマット
APIはすべて一貫したJSON構造を持ちます。成功時は "success": true、失敗時は "success": false と "error_code" を返却します。
JSON 共通レスポンス構造例 
{
  "success": true,
  "action": "アクション名",
  "timestamp": "2026-10-12T20:30:00+09:00",
  ... (個別データ) ...
}

記事一覧・検索API

外部システムへの最新お知らせ配信、ポータル連携、キーワード検索

GET /posts.php
一覧取得・検索・フィルタリング
掲載中のかわら版記事を一覧取得します。掲載期間、緊急度、カテゴリ、全文キーワードによる検索、およびページネーションに対応しています。
パラメータ 型 必須 初期値 説明
limit int 任意 10 取得件数（最大50件）
page int 任意 1 ページ番号（1始まり）
filter string 任意 active active: 掲載中のみ
today: 本日関連する記事
urgent: 超緊急・重要記事
pinned: ピン留め記事
all: 期限切れ含む全件
category string|int 任意 なし カテゴリーID (例: 2) または カテゴリーコード (例: facility)
q string 任意 なし タイトルおよび本文を対象とした全文キーワード検索（スペース区切り対応）
sort string 任意 created_desc created_desc, created_asc, event_asc (開催日順)
cURL 呼び出し例 
curl -X GET "http://192.168.1.16/kawara/api/posts.php?limit=5&filter=active"

埋め込みウィジェット (iframe対応UI)

外部Webポータル、電子カルテ端末Web画面に1行で埋め込める高品位UI

UI /widget.php
レスポンシブ埋め込みコンポーネント
HTMLの <iframe> タグを貼り付けるだけで、かわら版の最新記事一覧を美しく表示できます。テーマとレイアウトをURLパラメータで自由に変更できます。
パラメータ 選択肢 説明

header 1 (表示), 0 (非表示) ウィジェット上部の見出しヘッダーの表示切り替え
外部サイトへの貼り付けHTMLコード例 
<iframe src="http://192.168.1.16/kawara/api/widget.php?theme=hospital&limit=5" 
        width="100%" 
        height="360" 
        frameborder="0"

JavaScript埋め込みライブラリ (embed.js)

外部Webページ内の任意の <div> にインライン描画するVanilla JSスクリプト

JS /embed.js
ゼロ設定埋め込みスクリプト
iframe特有のスクロールバーや枠線を出さず、外部ページのDOMに自然に溶け込むインライン描画用ライブラリです。data-* 属性を書くだけで自動描画されます。また、プログラマブルに操作可能な window.KawaraAPI も提供されます。
HTML埋め込みコード (自動描画) 
<!-- 1. お知らせを表示したい場所に配置 -->
<div id="kawara-news-box"></div>

<!-- 2. スクリプトの読み込み -->
<script src="http://192.168.1.16/kawara/api/embed.js"
        data-container="#kawara-news-box"
        data-limit="5"
        data-filter="active"
        data-theme="light"></script>
JavaScript API (KawaraAPI オブジェクト)
独自のSPAやカスタムUIでデータを直接取得したい場合、グローバルオブジェクト window.KawaraAPI.fetchPosts() を利用できます。
JavaScript fetch 呼び出し例 
<script>
window.KawaraAPI.fetchPosts({ limit: 3, filter: 'urgent' })
  .then(data => {
    console.log('緊急お知らせ件数:', data.posts.length);
    data.posts.forEach(p => console.log(p.title));
  })
  .catch(err => console.error('取得エラー:', err));
</script>

Googleカレンダー 双方向API ＆ 個人登録連携

OAuth2 JWTサービスアカウントによる双方向同期 (includes/google_calendar_helper.php)

外部依存ライブラリ不要の高速実装
Google API Client PHP SDKなどの肥大化した外部パッケージを使用せず、純粋なPHP OpenSSL署名（RS256 JWTアサーション方式）でアクセストークンを自動取得・キャッシュします。
PHP関数名 HTTP操作 説明
get_google_calendar_events($cid, $start, $end) GET Google Calendar API v3 から指定期間の予定一覧を取得し、ローカルDBキャッシュ (google_calendar_events_cache) へ保存
create_google_calendar_event($cid, $data) POST Googleカレンダーに新しい予定を作成。作成直後にローカルキャッシュテーブルにも即時反映
update_google_calendar_event($cid, $eid, $data) PATCH 指定したイベントIDのタイトル、日時、場所、説明文を更新し、キャッシュ同期
delete_google_calendar_event($cid, $eid) DELETE Googleカレンダー上の予定を削除し、ローカルキャッシュからも即時削除
個人Googleカレンダー追加用 Web Intent リンク仕様
職員個人が自身のプライベートGoogleカレンダーにお知らせ予定を取り込めるよう、以下のURLスキーマによるWeb Intentリンクを自動生成しています。
https://calendar.google.com/calendar/render?action=TEMPLATE&text=[タイトル]&dates=[開始日時]/[終了日時]&details=[本文]&location=[場所]

LINE Messaging API 双方向連携

安否確認、重要伝達の一斉プッシュ配信、Flex Messageボタン回答

エンドポイント Method 説明
/kawara/api/line_webhook.php POST LINEプラットフォームからのWebhook受信。
① 4桁コード認証: かわら版画面に表示された4桁数字をLINEトークに送信すると、職員DB (staff.line_user_id) に自動紐付け。
② Flex Message ポストバック (action=ack): 「了解」「欠席」「質問」ボタン押下時に post_reads に既読ステータスを即時登録。
/kawara/api/line_post_notify_api.php POST 指定した記事の対象部署所属スタッフに対して、見栄えの良いFlex Messageを一斉プッシュ配信（管理画面および記事詳細から実行）。
/kawara/api/line_link_status.php GET 職員のLINE連携完了ステータスの確認および、連携用4桁ワンタイム認証コード（有効期限10分）の発行。

Windowsスプーラ連携による部署別ポスター・日報の物理排紙

エンドポイント Method 説明
/kawara/api/print_api.php POST パラメータ: action=dispatch_print, post_id, dept_ids, print_type

職員マスタ ＆ 統合認証基盤連携

人事システムとの連携 (stf_api.php) および 統合認証基盤 (auth_db) との接続

コンポーネント 仕様・役割
職員マスタAPI (stf_api.php) 院内人事データベース (staff_data.json) を基に、職員コード、氏名、カナ、所属部署、役職、雇用形態、電話番号、住所等の最新プロファイルをJSON形式で他システムへ提供。
統合認証基盤 (auth_db) /auth_db/api/v1/ が発行するセキュアなJWTトークンにより、電子カルテや他システムとシングルサインオン（SSO）連携。将来的にかわら版APIの書き込みエンドポイントにJWT認可ガード（Bearer Token）を導入可能。

端末認証 ＆ LINE多層防御API

院外スマホ用 30日暗号署名Cookie発行・LINE 6桁コード検証・即時失効エンドポイント (device_auth.php)

POST / GET /kawara/api/device_auth.php

Cloudflare WAFエッジ防御と連動し、院外スマホへ「30日間有効な暗号署名付き入室Cookie (kawara_device_token)」を発行・検証・失効させる中核APIです。

actionパラメータ メソッド パラメータ 概要とレスポンス
send_code POST / GET staff_id 対象職員の登録LINEへ6桁ワンタイム認証コード（有効10分）をプッシュ送信。
{"success": true, "message": "LINEに認証コードを送信しました。"}
verify_code POST staff_id, code 6桁コードを検証。成功時に Set-Cookie: kawara_device_token=...（30日有効、HttpOnly）を発行。
{"success": true, "message": "端末認証に成功しました。"}
revoke POST staff_id 管理者専用・端末即時失効
職員の device_token_version をインクリメントし、旧端末のCookieを即時無効化（スマホ紛失・退職時用）。
check GET - アクセス元が院内LANか、または有効な端末Cookieを保持しているかを即時判定。
{"success": true, "authenticated": true, "is_internal": false}

医師予定表システム（yotei）内部連携API

同一サーバー内の医師予定表APIと連携し、休診・外来・申し送りをスマホへリアルタイム配信

/yotei/api/today.php GET 本日の医師勤務サマリー（休診医師・診察担当医・全体会予定・申し送りメモテキスト）を取得。

Cloudflare外部トンネル 緊急制御API（物理キルスイッチ）

外部侵入経路（Cloudflaredトンネル）を即座に物理切断・再開し、インシデント発生時の被害をゼロにする緊急API

POST GET /kawara/api/tunnel_control.php
事務長・管理者専用 (二重ガード)

事務長（山本太 / staff_id = 15）またはシステム管理者（is_admin = true）のみ実行可能です。未認証アクセスは401、一般職員アクセスは403 Forbiddenで即座に拒絶されます。
本番サーバー上のWindowsサービス Cloudflared を sc.exe stop / start で直接操作し、外部トンネルを物理的に停止／再開します。

パラメータ 型 必須 説明
action string 必須 status: 現在のサービス稼働状態（RUNNING / STOPPED）を取得
stop: 外部トンネルを緊急停止（外部からの全通信を物理遮断＆ログ記録）
start: 外部トンネルを再開（外部スマホからのアクセス回復＆ログ記録）
レスポンス例 (停止完了時 JSON):
{
  "success": true,
  "status": "STOPPED",
  "is_online": false,
  "label": "遮断中 (OFF)",
  "color": "#dc2626",
  "message": "Cloudflare外部トンネルを正常に停止（遮断）しました。外部からの全アクセスが遮断されました。"
}
※ stop / start 実行時は、操作者氏名・スタッフID・日時が logs/security_audit.log に自動記録されます。
※ トンネル停止中も、院内LAN（電子カルテPC・院内Wi-Fi）によるアクセスには一切影響しません。
